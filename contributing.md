# Contribution Guidelines

Your contributions are welcome. This list is a curation, so a paper should earn its place by being useful as evidence or as a reference point for the field.

## Entry Format

```markdown
- [Paper Name](https://arxiv.org/abs/XXXX.XXXXX) - `market and universe` `test window` `costs` - What it does and why it is on this list. [Code](https://github.com/owner/repo)
```

- Use the three tags in this order. Write `costs not stated` when the paper does not say.
- Start the description with an uppercase letter and end it with a period.
- Add the `Code` link only for an official repository.
- Put new entries at the top of their section, which keeps each section newest first.

## Evidence

- Take numbers from the paper itself and name the version when versions disagree.
- Link the source of any rerun or criticism.
- Compare numbers across papers only with their protocols in view.

## Corrections

If an entry misdescribes a paper, or if a paper or its code has changed, please open an issue or a pull request. Authors are especially welcome to do so.

## Scope

In scope are papers where an LLM takes part in trading decisions, factor research, or the evaluation of those systems. General financial LLMs and general quantitative tools fit better in the lists under Related Lists.
